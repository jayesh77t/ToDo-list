# ToDo-list
✅ To-Do App (HTML, CSS, JavaScript)

A simple and responsive To-Do List web app built using HTML, CSS, and JavaScript. This app lets users manage their daily tasks efficiently with features like setting task priority and due dates.

📝 Features

✍️ Add and manage tasks

⏫ Set task priority (High, Medium, Low)

📅 Assign due dates

🗑️ Delete completed or unnecessary 

💾 Local storage support (tasks persist after refresh)

📱 Responsive design for all devices
